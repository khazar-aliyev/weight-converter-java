# Weight Converter in Java

A simple Java CLI program that asks the user for their weight and converts it between **kilograms (kgs)** and **pounds (lbs)** based on their choice.

## Features
- Interactive user prompt (`Yes/No` options).
- Case-insensitive input handling (`equalsIgnoreCase`).
- Accurate weight conversion using standard conversion rates ($1\text{ kg} \approx 2.2046\text{ lbs}$).
- Formatted output with two decimal places (`%.2f`).

## How to Run
1. Clone this repository.
2. Open the project in IntelliJ IDEA or any Java-supported IDE.
3. Run `Khazar.java`.
4. Follow the interactive console prompts.
